# Extension planning documents

The plan for making every Pata tool and every Mwalimu feature reachable from VS Code:

| # | Document | What it settles |
| --- | --- | --- |
| 1 | [Product Requirements](01-product-requirements.md) | Goals, the tool coverage table, VS requirements |
| 2 | [Technical Requirements](02-technical-requirements.md) | Module layout, tool resolution, testing, debugger, CLI dependencies |
| 3 | [App Flow](03-app-flow.md) | Activation, surfaces, create/edit/test/debug flows, error states |
| 4 | [Design Brief](04-design-brief.md) | Command titles, icons, status bar, walkthrough |
| 5 | [Implementation Plan](05-implementation-plan.md) | Roadmap, task tracker, decisions, launch checklist |

Change these documents by pull request. Requirements that need work in the Asili repo (CLI flags,
`pata-dap` requests) are tracked there as issues and listed in the Implementation Plan.
