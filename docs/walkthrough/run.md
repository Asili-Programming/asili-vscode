# Jenga na endesha

Tumia **Asili: Endesha** kujenga mradi na kutekeleza kazi yake kuu. Unaweza pia kuchagua lengo la
kujenga, kama `native`, `wasm`, `cortex-m` au `esp32`.

Use **Asili: Run** to build the project and run its entry point. You can also select a target such
as `native`, `wasm`, `cortex-m`, or `esp32`.
