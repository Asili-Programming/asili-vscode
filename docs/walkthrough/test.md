# Gundua na endesha majaribio

Fungua mwonekano wa **Testing** ili kuona majaribio yaliyogunduliwa na Pata. Endesha jaribio moja
au yote, au tumia amri ya chanjo kuona muhtasari wa mistari iliyotimizwa.

Open the **Testing** view to see tests discovered by Pata. Run one test or all tests, or use the
coverage command to see a summary of executed lines.
