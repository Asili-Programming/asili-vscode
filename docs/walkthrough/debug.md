# Tatua programu

Weka kituo cha kusimama ndani ya faili ya Asili, kisha ubonyeze **F5**. Pata-DAP inaweza kusimamisha
utekelezaji, kuendelea, kupiga hatua na kuonyesha vigeu.

Set a breakpoint in an Asili source file and press **F5**. Pata-DAP can pause and resume execution,
step through the program, and show variables.
